# Automatic cloud setup validation — 06/10/2026

The standalone installer contains a pinned Git bundle and the built frontend. It verifies payload/file checksums, bounded regular-file archive members, Git commit and checkout conflicts. Source extraction is tested offline against real temporary Git repositories; tar traversal/links/special entries, corruption, changed files, conflicting destinations, input/output collisions and repeated installation are covered. Dry-run performs no package installation or downloads.

The cloud setup orchestrator is tested with a copied script and stub commands. Tests cover sequential bootstrap/fetch/verify/profile gates, journal readiness, failure exit propagation, host gating and rerun. Windows shell tests explicitly use Git Bash; WSL is excluded. Resumable HTTP tests use simulated responses for interrupted transfers, valid/invalid ranges, servers ignoring Range, full partial promotion, retries and checksum failure.

An early integration test accidentally launched the real bootstrap in local WSL because the WSL launcher did not propagate its fixture environment. Apt installed FFmpeg/fonts/Python tools and updated Python 3.12 in that WSL distribution, and part of the core/model environment was created under `/opt/autodub/venvs`. We stopped the verified project process tree (PIDs 428, 437, 3385) while CUDA pip installation was starting; no project setup processes remained. At inspection, dedicated venv/cache directories measured approximately 66 MB/11 MB. Installed WSL packages and partial directories remain; they were not removed or rolled back without evidence about pre-existing state. This is a test isolation failure and does not validate cloud/GPU setup.

Tests were corrected to run a fixture-local script with explicit shell exports, fake OS/GPU/disk data and sentinel apt/sudo/network commands. The real project bootstrap cannot be reached by these tests. Final test totals and packaging verification are recorded in VALIDATION.md.

The actual GPU host reported by the user has Ubuntu 24.04.5, RTX 5060 Ti 16 GB and a working NVIDIA driver. We have not connected to that host or run this installer there. Local tests and preflight design do not establish CUDA model inference, workload quality, Docker GPU readiness or performance on that host. This installer uses native Python environments; missing NVIDIA Container Toolkit does not affect that execution path.
